Longitudinal Patient Health Prediction - from previous visits to the next visit

Question: given a patient's history up to the current visit, what outcome is likely at the next visit, and how reliable is that prediction?  |  Academic research prototype - not a clinically validated tool.

1Data (public, real)

  • GSE65391 - paediatric SLE cohort (NCBI GEO)
  • 157 patients, 923 visit records (avg 5.9 per patient)
  • Per visit: 14 labs, 8 treatment flags, SLEDAI + 6 organ items, age
  • Usable prediction points: 635 (111 patients with ≥3 records); flares = 17.2 %
  • No calendar dates: time = days since the patient's first record

2Target (one clear outcome)

yt+1 = 1  if  SLEDAIt+1 − SLEDAIt ≥ 4  else 0
  • "Flare at the next record" (≥4-point rise is a common SLEDAI flare cut-off)
  • A proxy label derived from SLEDAI - not clinician-adjudicated
  • Needs ≥2 records (current + one earlier) to measure change
  • Not predicted: readmission, complications, abnormal labs (not supported by this dataset)

3Leakage-free features (87)

Δxt = xt − xt−1   slope = Δxt / gap × 30   roll3 = mean(xt−2..t)
  • Trends for 11 variables (previous value, change, slope, 3-visit mean)
  • History: highest/mean SLEDAI so far, flares seen so far, visits since last flare, treatment changes
  • Excluded as future information: total visit count, span to last visit, biopsy timing/class, study split
  • Unit tests prove a visit's features do not change if later visits are altered

5Metrics

Precision = TP/(TP+FP)   Recall = TP/(TP+FN)   F1 = 2PR/(P+R)
Brier = mean (p − y)²   ECE = Σ (nb/n) |obsb − predb|
  • AUROC and PR-AUC (chance PR-AUC = flare rate 0.17)
  • Threshold chosen on out-of-fold training data only
  • Platt scaling for calibration; 95 % CIs by resampling patients (1000x)

6Uncertainty & explanation

f(x) = φ0 + Σi φi  (SHAP)    p̂ = meanb∈OOB pb
  • 60 bootstrap-by-patient models; a known patient is scored only by models that never saw them
  • Spread of the models (10-90 %) = reliability band
  • SHAP groups: recent trend / longer history / treatment / current values
Association ≠ causation: SHAP shows what the model uses, not what would happen if a treatment changed.

8Contribution (claimed carefully)

  • Direct static-vs-longitudinal comparison with paired patient-level intervals
